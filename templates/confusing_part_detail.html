{% if part == "= vs ==" %}

Assignment

The single equals sign is used to store a value in a variable. 

age = 20

Python stores the value 20 inside the variable age.

Comparison

The double equals sign is used to check whether two values are equal. 

age == 20

Python checks whether the value stored in age is equal to 20.

Try it yourself

age = 20
print(age == 20)

Remember

= → store a value

== → check whether values are equal

{% elif part == "append() vs extend()" %}

append()

Add one item

append() adds one item to the end of a list. 

numbers = [1, 2]
numbers.append(3)

The list becomes: 

[1, 2, 3]

extend()

Add items from another iterable

extend() adds the items from another iterable to the list. 

numbers = [1, 2]
numbers.extend([3, 4])

The list becomes: 

[1, 2, 3, 4]

Try it yourself

numbers = [1, 2]
numbers.append([3, 4])
print(numbers)

What do you think Python will print?

Remember

append() → adds one item

extend() → adds items from another iterable

{% elif part == "remove() vs pop()" %}

remove()

Remove by value

remove() searches for a value and removes it. 

numbers = [10, 20, 30]
numbers.remove(20)

The value 20 is removed.

pop()

Remove by position

pop() removes an item using its index. 

numbers = [10, 20, 30]
numbers.pop(1)

Index 1 refers to the second item, which is 20.

Try it yourself

numbers = [10, 20, 30]
removed = numbers.pop(1)

print(removed)
print(numbers)

What do you think Python will print?

Remember

remove() → uses a value

pop() → uses an index

{% elif part == "break vs continue" %}

break

Stop the loop

break immediately stops the loop. 

for number in range(5):
    if number == 2:
        break
    print(number)

When the number becomes 2, the loop stops completely.

continue

Skip the current iteration

continue skips the current iteration and moves to the next one. 

for number in range(5):
    if number == 2:
        continue
    print(number)

When the number is 2, that iteration is skipped, but the loop continues.

Try it yourself

for number in range(5):
    if number == 2:
        continue
    print(number)

What do you think Python will print?

Remember

break → stops the loop

continue → skips one iteration

{% elif part == "list vs tuple" %}

List

Changeable

A list can be changed after it is created. 

numbers = [1, 2, 3]
numbers[0] = 10

The list becomes: 

[10, 2, 3]

Tuple

Fixed

A tuple cannot have its individual values changed after it is created. 

numbers = (1, 2, 3)

Try it yourself

numbers = (1, 2, 3)
numbers[0] = 10
print(numbers)

What do you think Python will do?

Remember

List → changeable

Tuple → fixed

{% elif part == "List methods vs String methods" %}

List methods

Methods that work with lists

List methods are methods that we can use to work with items inside a list.

append()

Adds one item to the end of a list. 

numbers = [1, 2]
numbers.append(3)

print(numbers)

Output:

[1, 2, 3]

remove()

Removes a specific value from a list. 

numbers = [10, 20, 30]
numbers.remove(20)

print(numbers)

Output:

[10, 30]

sort()

Arranges the items of a list in ascending order. 

numbers = [3, 1, 2]
numbers.sort()

print(numbers)

Output:

[1, 2, 3]

String methods

Methods that work with strings

String methods are methods that we can use to work with text.

upper()

Converts letters to uppercase. 

name = "python"
print(name.upper())

Output:

PYTHON

lower()

Converts letters to lowercase. 

name = "PYTHON"
print(name.lower())

Output:

python

strip()

Removes spaces from the beginning and end of a string. 

name = "  Python  "
print(name.strip())

Output:

Python

split()

Splits a string into smaller parts and gives you a list. 

sentence = "I love Python"
print(sentence.split())

Output:

['I', 'love', 'Python']

Try it yourself

name = "python"
name.append("!")

What do you think Python will do?

Remember

Before using a method, ask:

What type of object am I working with?
